term: "Schema Markup"
slug: "schema-markup"
category: "SEO"
definition: "Schema Markup is a standardized vocabulary of tags and attributes that website owners add to HTML to help search engines better understand the content on their web pages."
---

Schema Markup is a form of structured data added to a website's HTML code. It uses a specific vocabulary, largely derived from Schema.org, to classify and label elements on a page, such as a product's price, an event's date, or an author's name. This allows search engines to interpret the meaning and relationships of content more accurately, moving beyond simple keyword recognition.

This structured data enables search engines to display content in richer and more informative ways directly in search results, often appearing as "rich snippets." These can include star ratings for reviews, product availability, event dates, or cooking times for recipes. By providing search engines with explicit information about page content, Schema Markup helps improve a website's visibility and presentation in search engine results pages. Websites that implement it effectively can see increased click-through rates because their listings offer more relevant details at a glance, helping users quickly identify pertinent information. For example, a restaurant website can use Schema Markup to specify its cuisine type, opening hours, average price range, and customer reviews. When a potential diner searches for local restaurants, search engines can display this specific information alongside the search result, making the restaurant's listing more informative and appealing to users looking for particular dining options.
