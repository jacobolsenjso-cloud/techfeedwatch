## Technical Breakdown

Core Web Vitals consist of three distinct metrics: Largest Contentful Paint (LCP), First Input Delay (FID), and Cumulative Layout Shift (CLS). Each metric targets a specific aspect of the user's perception of a web page.

LCP measures the time it takes for the largest content element on a page to become visible within the viewport. This is typically an image, video, or a large block of text. A good LCP score is under 2.5 seconds, signaling that users perceive the page as having loaded quickly. Optimizing LCP often involves server response time improvements, efficient image loading, and prioritizing critical rendering path resources.

FID quantifies a page's responsiveness to user interaction. It measures the time from when a user first interacts with a page (e.g., clicking a button or link) to the time the browser is actually able to respond to that interaction. A good FID score is under 100 milliseconds. Poor FID often indicates heavy JavaScript execution blocking the main thread, delaying user feedback. Solutions include code splitting, deferring non-critical JavaScript, and optimizing third-party script loading.

CLS assesses the visual stability of a page. It measures the unexpected shifting of page content during loading, which can be disorienting and frustrating for users. A good CLS score is below 0.1. Common causes include images or videos without dimension attributes, dynamically injected content, and ads that resize themselves. Addressing CLS involves reserving space for content that loads asynchronously and avoiding inserting new content above existing content unless user-initiated.
