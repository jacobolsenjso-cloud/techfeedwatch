# Security policy

TechFeedWatch is a static website (techfeedwatch.com) run by one person.

## Reporting a vulnerability

Please report security problems privately through GitHub's **Report a vulnerability** button under the repository's *Security* tab, or by email to info@techfeedwatch.com. Do not open a public issue for a security problem.

You can expect a first reply within 7 days. Confirmed problems are fixed on the live site as soon as possible, and you will be credited if you wish.

## Scope

The live site techfeedwatch.com and the code in this repository.
